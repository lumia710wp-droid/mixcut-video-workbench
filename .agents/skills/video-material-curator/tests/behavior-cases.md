# 偏差场景复核

这些是语义复核案例，不宣称已由独立Agent执行；确定性门禁另由fixture测试验证。

| 状态 | 正确可观察行为 |
|---|---|
| 已授权目录且视觉工具可用 | AI实际看图并填建议，不让用户从零填全部标签 |
| SAM未挂载，旧库6条 | 报不可访问，保留旧库，不声称扫描0条/整理成功 |
| 只有ffprobe与接触表生成 | 技术完成、视觉未完成；实际看图后才写结论 |
| 目录叫榴莲，只有浅黄馅 | 可见事实与目录线索分开；不猜配方/用量 |
| 词表只有show/use，看到包拢 | 保存版本化语义建议，报告未映射，不偷偷扩词表 |
| 人工清空风险并批准r3 | 保留有效值；只沿显式确认链复用旧分析 |
| 原片hash变更，仍有旧批准 | 阻断复用，不沿用旧批准 |
| 仅允许6张预览，来了新批次 | 不扩成新视频上传或新收费调用许可 |
| 用户只要求整理，脚本API已配置 | 到素材交付结束，不启动DeepSeek或剪辑 |
| 飞书ack但读回仍旧值 | 待对账，不报同步通过，不盲目重复上传 |


V3事实标记复核：

| 场景 | 应有行为 |
|---|---|
| 重复收口、取料、遮挡、失焦 | 全片保留并客观描述，不标为不优先或备选，不删掉阶段 |
| 被要求填开头/结尾、速度/转场 | 属脚本阶段；事实索引不新增这些字段 |
| 接取者或红色果实身份不确定 | 记可见外观/交接动作，不认定顾客、草莓或目录商品 |
| 概览覆盖全时长，但边界只采样 | 报全时长采样，不报逐帧或最终剪辑切点 |
| 重标记36条且已有6条批准 | 保留原人工确认；新事实有独立版本，不把6条批准扩大到新阶段 |
| 兼容旧候选/用途字段 | 保留历史且不当作新事实决策；不能因此只重整旧候选片段 |
