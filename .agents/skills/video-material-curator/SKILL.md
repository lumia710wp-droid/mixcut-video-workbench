# Purpose

把实拍视频整理为可追溯、按时间检索的事实索引。AI实际看画面并填写标记，人工核对商品和不确定项。素材整理回答“画面里有什么、何时发生、看得是否清楚”；脚本决定“用不用、用哪段、怎么剪”。

# Trigger

视频素材入库、盘点、AI视觉打标、时间轴内容拆解、重标记与素材库增量整理。仅写脚本、剪辑、渲染、封面或发布时不单独使用。

# Dependencies and Inputs

需工作区、授权原片根目录、本轮范围、已有探测/抽帧工具和实际看本地画面的能力。先读项目规则、检查点和原有记录，复用既有工具。Mixcut读取[接入说明](references/mixcut-adapter.md)。标记字段和校验读[事实标记契约](references/factual-marking.md)。飞书同步时再加载lark-base。

云端视觉仅在已有提供方、送检范围和额度许可下使用；文字模型/TTS凭据不表示视觉许可。可用交互看图时直接做，不默认要求新API或重装工具。

# Hard Constraints

- HC-001 原片只读；不移动、覆盖、删重复或扫描全盘。检查根目录挂载、符号链接和路径逃逸。不可访问是失败，不能解释成0条并覆盖旧索引。
- HC-002 实际观看才算视觉标记；探测、抽帧、生成接触表不等于已看图。按采样事实报告覆盖度，不称逐帧或连续观看；未听音不称转写完成。
- HC-003 标记完整源时间轴，包括起手、取料、机位移开、遮挡、重复、失焦与片尾。阶段边界是观察定位，不能冒充脚本裁切点。漏看、模糊、不确定处明确记录，按需加密查看。
- HC-004 不生成取用建议、主用/备选排名、开头/主体/结尾角色、推荐剪辑入出点、速度、转场、裁切、成片音量或字幕安排。不因质量差预先剔除阶段；客观记录模糊、遮挡、构图和发生时间。选材及所有剪辑决定留给脚本。
- HC-005 可见事实、商品确认值和目录/外观线索分开。未知SKU、配方、用量、价格、功效保持未知。接取者身份不能自动认作顾客；背景包装和另一颗产品不证明本产品配方或同一制作轮次。
- HC-006 原文件身份、观察阶段身份、生产批准分别保存；多个阶段仍属于一个源。遵守固定词表，未映射动作保存版本化semantic_tags并报告缺口，不把空标签报成齐全。相似动作/疑似重复与已验证完全重复分开，不虚构全库视觉去重。
- HC-007 现有人工确认和批准保留。AI不代签；用户明确确认才按授权绑定当前版本/hash。新事实分析不自动获批，也不把旧范围批准扩大到全片。重整新建版本，保留旧观察与来源证据。
- HC-008 媒体保存本地，仅传路径/附件引用及摘要，不输出编码。批量每批看图后立即写标记和检查点，可恢复续接；不把已生成接触表直接批量标成已看。

# Workflow

1. **恢复和盘点**：核对本轮授权范围、挂载、源文件与现有索引；排除AppleDouble等非视频，失败单列。记录hash、时长、尺寸/旋转、帧率、音轨；已确认值只作引用。
2. **准备证据**：沿用匹配源hash及时间映射的审核副本；保存带源时间的全时长采样和必要原分辨率帧。一般以每秒观察定位，密度按变化调整；切镜、快速动作、不确定位置加密。不要只抽中间或只看历史候选窗口。
3. **实际看图并标记**：逐源填写全片内容摘要、连续阶段、主体/动作/场景/景别/机位变化、源时间动作点、质量与遮挡、同源相似动作、商品线索和不确定项。保持客观描述；每秒图可逐点记，也可用明确范围描述同一稳定状态。记录已看证据、时间与未覆盖部分。
4. **校验和入库**：检查身份/hash、全片阶段无缺口或重叠、事件范围、证据文件/时间、禁用剪辑决策字段、词表和版本链。写入项目现有版本化索引；兼容旧系统时不得把“阶段范围”误写为“已批准可用区间”，旧用途字段不得重新引入选材建议。
5. **审核和交接**：人工主要核对商品/品牌和不确定项；AI不能把整理完成当生产批准。按授权同步并读回；只收到ack不报同步验证完成。交付全片事实索引、可检索时间点与本地证据；到此结束，不启动脚本、TTS或剪辑。

# Output and Validation

输出：源/阶段索引、逐源事实标记、源时码关键帧、质量/标签缺口、不确定项、分析方式与实际观看覆盖、源hash和标记hash、审核/同步状态、检查点绝对路径。报告发现/技术有效/已视觉标记/失败/待确认数量；不统计“主候选总时长”。

[check_facts.py](scripts/check_facts.py) 校验新事实标记的覆盖、字段、源和证据hash；只能证明结构与身份，不能证明模型看懂或人审。[check_handoff.py](scripts/check_handoff.py) 仅用于既有Mixcut旧proposal交接兼容检查，不能把旧start/end可用窗口当本版全片标记规范。脚本修改后跑对应回归；行为按[偏差场景](tests/behavior-cases.md)复核。

# Recovery

缺挂载/权限/证据/工具时保留既有数据，只阻断依赖步骤。未知结果先对账，不盲目重发或付费。相同问题两次失败后记录限制并切换可逆替代路线；扩大许可范围才问用户。源、采样、字段或标记规范变化需新版本复查，不复制旧“已看完”状态冒充重整。
