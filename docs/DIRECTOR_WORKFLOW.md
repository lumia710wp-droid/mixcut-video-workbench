# 素材与剪辑流程

1. 使用 `video-material-curator` 整理本机素材：记录真实画面、时间区间与版本，形成可检索的事实；原片保持只读。商品和标签由使用者根据自己的素材维护。
2. 在工作台填写目标、风格、时长和需要的口味范围。脚本 AI 生成文字和标题样式，使用者确认。文字阶段根据目标长度估算，不提前生成配音。
3. `video-script-material-director` 根据已确认文字拆分画面需求，调用本地 `material-search` 分批检索已入库事实，选择镜头、切点和顺序。索引和完整素材留在本机；已有事实足够时直接复用，不逐条重新审看。信息不足或相互矛盾时，仅补查必要片段。
4. 编导方案及标题样式回填飞书，人工审核。修改方案需重新审核；不要手动伪造审核状态或绕过版本校验。
5. 通过审核后，Codex 调用项目固定剪辑入口 `./mixcut director run --task TASK_ID`。程序生成配音、测量并按约定时长处理，严格使用已审核的标题与镜头方案，交由独立安装的 OpenChatCut 执行。
6. 核对成片内容及技术结果后，Codex 制作抖音、小红书和视频号封面及发布文案，按项目 Skill 的 `references/delivery.md` 准备候选包并回填飞书。用户对视频、四张封面和三平台文案一起验收；修改后需要重新验收。技术检查不能代替内容审片。发生失败或结果未知时先检查本地回执及飞书状态，避免自动重复付费请求或写入。

具体命令和计划结构见两项 Skill 的 `references/`；用 `./mixcut --help` 查看程序入口。实际支持的配置、审核字段和数据结构以代码和运行结果为准。
